# DevOps-lab-8
**Тақырыбы:** Docker орнату және алғашқы контейнер
1. GitHub Codespaces бұлтты ортасында Docker жүйесі тексерілді.
2. `docker run hello-world` командасы арқылы алғашқы контейнер сәтті іске қосылды.
### Қолданылған негізгі командалар тізімі:
- `docker run hello-world` — контейнерді жүктеп, іске қосу.
- `docker ps -a` — барлық контейнерлер тізімін көру.
